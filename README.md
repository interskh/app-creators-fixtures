# app-creators-fixtures
Fixture apps for app-creators skills: the same to-do app in every framework

- `todo-vite/`: Vite + TypeScript PWA
- `todo-expo/`: Expo + React Native + TypeScript app with bundle ids, icons, and a photo-library permission
- `todo-flutter/`: Flutter app (iOS and Android) with ids, icons, and a photo-library permission
- `todo-swift/`: SwiftUI iOS app with an id, icon, and a photo-library permission; hand-written, never built
