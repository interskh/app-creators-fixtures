# todo-kotlin

A tiny to-do list app: native Android in Kotlin with Jetpack Compose (Material 3). Items persist in `SharedPreferences`, and each item can carry a photo, taken with the camera or chosen with the system photo picker.

```sh
./gradlew testDebugUnitTest
./gradlew bundleRelease assembleRelease
```

The Gradle commands need a JDK 17 or newer and an Android SDK with platform 37 and build-tools 36.0.0 or newer. Put the SDK path in `local.properties` (`sdk.dir=...`, ignored by git) or set `ANDROID_HOME`.

This is the fixture used by the `publish-readiness` skill in the sibling repo `app-creators-skills`, and by `publish-android` later. It has the name "Todo", the application id `io.github.interskh.todo`, version `1.0` (code 1), minSdk 24, compileSdk and targetSdk 37, and one privacy-relevant permission: `android.permission.CAMERA`.

## How it was made

No Android Studio GUI was used. The files were written by hand to match what Android Studio's "Empty Activity" (Jetpack Compose) new-project template generates. The template source was read from the AOSP `platform/tools/base` (`wizard/template-impl`, revision `86ccf01`) and `platform/tools/adt/idea` (`android-npw`, `android/resources/templates/project/project_ignore`) repositories on 2026-11-03. The build files follow the template's AGP 9 output: version catalog, `com.android.application` plus the Kotlin Compose plugin with built-in Kotlin, `compileSdk { version = release(...) }`, and R8 `optimization { enable = true }` with `src/main/keepRules/rules.keep`.

Generated by the template, kept as is: `.gitignore`, `gradle.properties` (with `android.useAndroidX` left out, as the template does for AGP 9), `settings.gradle.kts`, the root `build.gradle.kts`, `ui/theme/` (Color, Theme, Type), `themes.xml`, `backup_rules.xml`, `data_extraction_rules.xml`, `keepRules/rules.keep`, and the manifest skeleton. The wrapper comes from `gradle wrapper --gradle-version 9.8.2`.

Hand-written: `MainActivity.kt` (the to-do screen and the photo code), `Todos.kt` (the to-do logic and the save format), `TodosTest.kt`, the CAMERA permission and `uses-feature` lines in the manifest, the launcher icons, and `app/build.gradle.kts` values (applicationId, SDK levels, no `androidTest` dependencies, no `ExampleInstrumentedTest`).

Versions, from release pages read on 2026-11-03: Android Gradle plugin 9.5.0 (minimum Gradle 9.6.0, JDK 17, build-tools 36.0.0, API 37), Gradle 9.8.2 (`services.gradle.org/versions/current`), Kotlin 2.4.21 (kotlinlang.org releases page), Compose BOM 2026.09.00, activity-compose 1.13.0, core-ktx 1.19.1, lifecycle-runtime-ktx 2.11.0 (Google Maven metadata). The Compose BOM is newer than the template's pinned `2026.02.01`.

## Permission

`CAMERA` is declared in `AndroidManifest.xml` and used in `MainActivity.kt` as `Manifest.permission.CAMERA` before a `TakePicturePreview` capture, so `permissions-declared` sees a real API and its `<uses-permission>`. The two `<uses-feature>` lines with `required="false"` stop Google Play from hiding the app on devices without a camera, as the Android `uses-feature` page says. Choosing a photo uses the system photo picker (`PickVisualMedia`), which needs no permission. `READ_MEDIA_IMAGES` and `READ_MEDIA_VIDEO` are not declared: Google Play's Photo and Video Permissions policy lets an app request them only when the system pickers do not cover its core function.

## Icons

Legacy PNG launcher icons `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` at 48, 72, 96, 144, and 192 px, resized with `sips -z` from `todo-expo/assets/icon.png`, no alpha. The template's adaptive vector icon is not used, because `check-readiness.py` gives `UNKNOWN` for vector and layer drawables and can judge PNG sizes. There is no round or adaptive icon.

## Verified

Run on 2026-11-03 with the Android Studio JDK 21 and the SDK already installed (nothing was downloaded under the SDK folder; Gradle libraries went to the Gradle cache):

- `./gradlew testDebugUnitTest`: 6 unit tests pass (add trims and keeps order, blank text ignored, toggle, delete, save and load round trip, load skips broken lines).
- `./gradlew bundleRelease assembleRelease`: succeeds. The bundle has no signing config, so the APK is `app-release-unsigned.apk`.
- `apkanalyzer manifest print` on the APK and `bundletool dump manifest` on the bundle both show package `io.github.interskh.todo`, `targetSdkVersion` 37, and `CAMERA`.
- `check-readiness.py --platform android` gives `PASS` for `app-name`, `icon-sizes`, and `permissions-declared`. `package` is `UNKNOWN` until `--resolved` gets either built manifest, then `PASS`.
